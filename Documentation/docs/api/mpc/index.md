title: "Model Predictive Controllers"

The `jMPC` Class represents a Model Predictive Controller together with properties and functions required to simulate it, analyze it, and implement it, whether in Matlab, Simulink or an Embedded Platform. The aim of this toolbox is to break the barriers to MPC, allowing simple intuitive design and tuning, thus not all commercial MPC properties have been written into the algorithm.

|  |  |
| --- | --- |
| [`jMPC`](./jmpc.md) | Create a jMPC MPC Controller |
| [`jMPCset`](./jmpcset.md) | Create or edit jMPC options structure |
| [`sim`](./sim.md) | Simulate an MPC controller in a given simulation environment |
| [`mpcsolve`](./mpcsolve.md) | Solve for the optimal MPC control input |
| [`plot`](./plot.md) | Plot MPC results |
| [`compare`](./compare.md) | Compare two MPC simulations |
| [`GetMPCToolboxObj`](./get-mpc-toolbox-obj.md) | Return a Matlab MPC Toolbox® object based on the `jMPC` object |

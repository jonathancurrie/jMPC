Provided with this software are several example setups which allow for new users to get familiar with the software.

To load an example, click File -> Load -> Example Models:

![gui load example](/img/jmpc/gui_load_example.png)

You will be presented with a new window, containing a list of currently saved examples:

![gui example](/img/jmpc/gui_example.png)

Each example is complete with a functional description, displayed as each example is selected. Click OK to select an example, which will be automatically loaded into the GUI. At this point you can run the example as is, or modify existing settings as required.

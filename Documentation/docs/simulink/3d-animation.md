The toolbox comes with a small number of Simulink 3D Animated models for visualizing the response of a jMPC controller. These all require the [Simulink 3D Animation Toolbox](https://au.mathworks.com/products/3d-animation.html).

All models can be found in `Simulink/3D MPC Demos`. All models will also run automatically with the correct settings and models loaded when the "Run" button is pressed.
